# elfe

Repositorio de práctica para aprender Git y GitHub.  
Este proyecto servirá como base para experimentar con ficheros, commits y control de versiones.  

---

## 📂 Contenido
- `README.md` → archivo principal del proyecto (esta página).  
- `README2.md` → archivo auxiliar con pruebas o notas adicionales.  

---

## 🎯 Objetivo del proyecto
- Familiarizarse con la creación y manejo de repositorios en GitHub.  
- Aprender a subir archivos, modificarlos y llevar un historial de cambios.  
- Experimentar con la edición web y local mediante `git`.
